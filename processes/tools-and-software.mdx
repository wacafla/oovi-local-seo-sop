Using the right tool for the right job keeps our work consistent and makes collaboration easier. This page lists every approved tool at Oovi, what it's for, and how to use it correctly. If a tool isn't listed here, assume it hasn't been approved for client work until you've confirmed otherwise with the Operations Manager.

## Tool Categories

<Tabs>
  <Tab title="SEO & Research">
    These are the core platforms used for keyword research, competitive analysis, and performance monitoring.

    <CardGroup cols={2}>
      <Card title="SEMrush" icon="magnifying-glass-chart">
        Used for keyword research, competitor analysis, site audits, and the On-Page SEO Checker. We operate on a shared team seat — if you plan to run a large site crawl, coordinate with the team in Slack first to avoid exhausting the crawl quota mid-week.
      </Card>
      <Card title="Ahrefs" icon="link">
        Used for backlink analysis, link prospecting, rank tracking, and content research via Content Explorer. Also a shared team seat — be mindful of report export limits and avoid bulk exports unless necessary.
      </Card>
      <Card title="Google Search Console" icon="google">
        Used to monitor organic performance, index coverage, Core Web Vitals, and manual actions for each client. You must be added to each client's GSC property before working on their account. Never access a client's GSC through a personal Google account.
      </Card>
      <Card title="Google Analytics 4" icon="chart-line">
        Used for traffic analysis, conversion tracking, and user behavior reporting. Like GSC, access is property-specific — confirm you have the correct client property open before pulling any data. GA4 data is used in monthly reports and performance reviews.
      </Card>
    </CardGroup>
  </Tab>
  <Tab title="Local SEO">
    These tools are specifically used for local search optimization tasks including GBP management, citation building, and local rank tracking.

    <CardGroup cols={2}>
      <Card title="BrightLocal" icon="location-dot">
        Our primary platform for local rank tracking, citation audits, reputation monitoring, and GBP audits. Each client has a dedicated project in BrightLocal — always work within the correct project. Use BrightLocal's rank tracker for weekly position checks and the citation audit tool before starting any citation campaign.
      </Card>
      <Card title="Google Business Profile Manager" icon="store">
        Accessed at business.google.com. Used for all GBP editing, post publishing, review management, and insights review. Always access client GBPs through **agency access via the client's Google account delegation** — never log in using your personal Google account or create new profiles under personal credentials.
      </Card>
      <Card title="Whitespark" icon="building">
        Our secondary citation tool, used for the local citation finder and to supplement BrightLocal citation data. Used primarily during citation audits and when building citations in niche or industry-specific directories that BrightLocal doesn't cover.
      </Card>
    </CardGroup>
  </Tab>
  <Tab title="Project Management">
    These tools keep our team organized, accountable, and communicating effectively.

    <CardGroup cols={2}>
      <Card title="ClickUp" icon="list-check">
        The primary platform for all tasks, deadlines, and client project management. Every deliverable must have a corresponding task in ClickUp — if it doesn't exist in ClickUp, it doesn't exist. Use task descriptions, due dates, and status updates to keep the team informed. Log QC approvals and escalations as task comments.
      </Card>
      <Card title="Slack" icon="slack">
        Internal team communication. Use dedicated project and department channels for relevant discussions. Keep client-sensitive data (NAP details, login credentials, personal client information) out of public channels. Use Slack DMs for direct team member communication and urgent escalations.
      </Card>
      <Card title="Google Drive" icon="folder-open">
        All client files, report templates, SOPs, and shared documents live here. Files are organized by client folder — always save work in the correct client directory. Never store work-in-progress files locally; keep everything in Drive so the team has access.
      </Card>
      <Card title="Zoom / Google Meet" icon="video">
        Used for all client-facing calls and internal team meetings. Always join from a **company account**, not a personal one. If you're running a client call, test your audio and video beforehand, and use a professional background.
      </Card>
    </CardGroup>
  </Tab>
  <Tab title="Content & Writing">
    These tools support the content creation, editing, and quality assurance process for all written deliverables.

    <CardGroup cols={2}>
      <Card title="Google Docs" icon="file-lines">
        The standard platform for all content drafting and collaborative editing. All content is written, reviewed, and approved in Google Docs before being published anywhere. Keep documents organized within the correct client folder in Google Drive.
      </Card>
      <Card title="Hemingway App" icon="pen-nib">
        Used for readability checks before any content is submitted for approval. Aim for a Grade 8 reading level or lower on service and location pages. The app highlights overly complex sentences, passive voice, and adverb overuse — address each flagged item before moving on.
      </Card>
      <Card title="Grammarly" icon="spell-check">
        Used for proofreading and grammar checking on all client-facing content. Run every piece through Grammarly before submitting it for Account Manager review. Pay attention not just to corrections, but to clarity and tone suggestions — Grammarly often catches subtle issues that a quick read-through misses.
      </Card>
      <Card title="Copyscape" icon="shield-halved">
        Used for duplicate content checking on new pages and blog posts before they're published. Any result above 10% similarity requires revision. Log that a Copyscape check was completed in the ClickUp task for that content piece.
      </Card>
    </CardGroup>
  </Tab>
</Tabs>

## Requesting New Tools

<Note>
  If you discover a tool that could meaningfully improve your workflow or fill a gap in our current stack, submit a request to the Operations Manager. Include the tool name, monthly or annual cost, your specific use case, and a comparison to any existing tools it would replace or supplement. Unapproved tools should not be used for client work — using unauthorized platforms for client data creates security, compliance, and accountability risks.
</Note>

## Password Management

<Warning>
  All tool credentials are stored in the agency password manager (1Password or LastPass — confirm the current platform with your manager during onboarding). Never store passwords in ClickUp task descriptions, Slack messages, or Google Docs. Never share credentials via email. If you need access to a tool, request it through the Operations Manager — do not share or reuse another team member's login.
</Warning>
